# ✅ Чек-лист развёртывания системы удалённых клиентов

## 📋 Подготовка

- [ ] Загружено на Replit (основной бот)
- [ ] Обновлены зависимости: `pip install -r requirements.txt`
- [ ] Токен бота установлен в `telegrambot.apikey` или переменную окружения

## 🔧 Установка на локальных машинах

### Для каждого компьютера с локальной папкой downloads:

- [ ] Python 3.7+ установлен
- [ ] Установлены зависимости: `pip install -r requirements_client.txt`
- [ ] Определён путь к папке downloads
- [ ] Определён уникальный ID клиента (например: `home_pc`, `office_london`)
- [ ] Определён порт для API (по умолчанию: 5000)

## 🚀 Запуск локального клиента

### Windows

```bash
# Способ 1: Команда
python local_client.py --id my_pc --folder C:\Users\YourName\Downloads --port 5000

# Способ 2: Батник (сохраните как start_client.bat)
@echo off
python local_client.py --id my_pc --folder C:\Users\YourName\Downloads --port 5000
pause
```

- [ ] Клиент запущен
- [ ] API доступно по адресу (видно в консоли)
- [ ] Проверен доступ: `curl http://localhost:5000/health` (или используйте браузер)

### Linux/Mac

```bash
# Установить права на выполнение
chmod +x run_local_client.sh

# Способ 1: Скрипт
./run_local_client.sh my_pc /home/user/downloads 5000

# Способ 2: Прямая команда
python local_client.py --id my_pc --folder ~/downloads --port 5000
```

- [ ] Клиент запущен
- [ ] API доступно по адресу (видно в консоли)
- [ ] Проверен доступ: `curl http://localhost:5000/health`

## 🌐 Сетевая конфигурация

### Определение локального IP адреса

**Windows:**
```cmd
ipconfig
```
- [ ] Найден IPv4 Address в разделе Ethernet или Wi-Fi
- [ ] Запомнен IP адрес (например: `192.168.1.100`)

**Linux:**
```bash
ifconfig
```
- [ ] Найден IP адрес (inet адрес)

**Mac:**
```bash
ifconfig | grep inet
```
- [ ] Найден IP адрес

### Тестирование доступности

- [ ] Локальная машина может достучаться до API (тот же компьютер):
  ```bash
  curl http://localhost:5000/health
  ```

- [ ] Если бот на другой машине, проверьте доступность:
  ```bash
  curl http://192.168.1.100:5000/health
  ```

### Firewall настройки (если требуется)

**Windows:**
- [ ] Разрешен доступ к портам в Windows Defender Firewall
- [ ] Или открыт доступ для Python приложения

**Linux:**
- [ ] Если используется `ufw`:
  ```bash
  sudo ufw allow 5000
  ```

## 🧪 Тестирование системы

### Проверка здоровья клиента

```bash
curl http://192.168.1.100:5000/health
```

Ожидаемый ответ:
```json
{
  "status": "ok",
  "client_id": "home_pc",
  "local_folder": "...",
  "available_space": ...
}
```

- [ ] API отвечает с кодом 200

### Проверка информации о клиенте

```bash
curl http://192.168.1.100:5000/info
```

- [ ] Получена информация о размере папки и количестве файлов

### Тестирование загрузки файла

```bash
# Создайте тестовый файл
echo "test content" > test.txt

# Загрузьте его
curl -F "file=@test.txt" http://192.168.1.100:5000/upload
```

- [ ] Файл успешно загружен
- [ ] Файл появился в папке downloads

### Тестирование скачивания файла

```bash
curl -O http://192.168.1.100:5000/download/test.txt
```

- [ ] Файл скачан успешно

### Тестирование списка файлов

```bash
curl http://192.168.1.100:5000/list
```

- [ ] Получен список файлов в JSON формате

### Тестирование в Telegram боте

- [ ] Открыто меню: 📡 **Удалённые хранилища**
- [ ] Нажато: 📂 **Просмотр файлов**
- [ ] Выбран добавленный клиент
- [ ] Отображается список файлов с точными названиями и размерами

## 🚀 Запуск как сервиса (опционально)
