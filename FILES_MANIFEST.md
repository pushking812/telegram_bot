# 📦 Список всех новых файлов системы удалённых клиентов

## Файлы системы (обязательные для работы)

### 1. `local_client.py` ⭐ ВАЖНО
**Размер:** ~325 строк  
**Язык:** Python 3.7+  
**Зависимости:** Flask, Flask-CORS  

**Назначение:** Локальный сервер API для доступа к файлам на одном компьютере  

**Функциональность:**
- REST API для загрузки/скачивания файлов
- Проверка статуса и информация о папке
- Логирование всех операций
- Security: предотвращение path traversal атак

**Использование:**
```bash
python local_client.py --id home_pc --folder ~/downloads --port 5000
```

**Сумма контрольная:** ~12KB исходного кода

---

### 2. `remote_storage.py` ⭐ ВАЖНО
**Размер:** ~340 строк  
**Язык:** Python 3.7+  
**Зависимости:** aiohttp  

**Назначение:** Менеджер для управления всеми подключёнными удалёнными клиентами  

**Функциональность:**
- Регистрация и удаление клиентов
- Асинхронная проверка статуса клиентов
- Управление загрузкой/скачиванием файлов
- Сохранение конфигурации в `remote_clients.json`

**Основные классы:**
- `RemoteClient` - представление одного клиента
- `RemoteStorageManager` - менеджер всех клиентов
- `get_remote_storage_manager()` - глобальный экземпляр

**Сумма контрольная:** ~13KB исходного кода

---

### 3. `handlers/remote_handlers.py` ⭐ ВАЖНО
**Размер:** ~360 строк  
**Язык:** Python 3.7+  
**Зависимости:** python-telegram-bot  

**Назначение:** Обработчики Telegram команд для управления удалёнными клиентами  

**Функциональность:**
- Меню управления удалёнными хранилищами
- Добавление/удаление клиентов
- Просмотр статуса клиентов
- Просмотр файлов на клиентах
- ConversationHandler для диалога с пользователем

**Основные функции:**
- `remote_storage_menu()` - главное меню
- `remote_status()` - показать статусы
- `remote_add_client_*()` - добавление клиента
- `remote_browse_*()` - просмотр файлов
- `remote_delete_*()` - удаление клиента

**Сумма контрольная:** ~14KB исходного кода

## Утилиты (запуск и демонстрация)

### 1. `run_local_client.bat` (Windows)
**Назначение:** Батник для запуска локального клиента на Windows  

**Содержит:**
- Установка параметров по умолчанию
- Красивый вывод информации
- Запуск Python скрипта

**Использование:**
```batch
run_local_client.bat
# или с параметрами
run_local_client.bat my_pc C:\Users\John\Downloads 5000
```

---

### 2. `run_local_client.sh` (Linux/Mac)
**Назначение:** Shell скрипт для запуска на Linux/Mac  

**Содержит:**
- Установка параметров по умолчанию
- Создание папки если её нет
- Запуск Python скрипта

**Использование:**
```bash
chmod +x run_local_client.sh
./run_local_client.sh my_pc ~/downloads 5000
```

---

### 3. `demo_clients.py` 🧪
**Размер:** ~80 строк  
**Назначение:** Демонстрация системы - запуск нескольких клиентов  

**Функциональность:**
- Запуск 3 тестовых клиентов с разными портами
- Автоматическое создание папок
- Красивый вывод информации
- Graceful shutdown при Ctrl+C

**Использование:**
```bash
python demo_clients.py
```

## Конфигурационные файлы

### 1. `remote_clients.json` (создаётся автоматически)
**Назначение:** Сохранение конфигурации всех подключённых клиентов  

**Формат:**
```json
[
  {
    "client_id": "home_pc",
    "name": "Home PC",
    "url": "http://192.168.1.100:5000",
    "is_online": true,
    "last_check": "2024-02-04T10:30:15",
    "folder_size": 5368709120,
    "file_count": 1024,
    "available_space": 536870912000
  }
]
```

**Где создаётся:** В главной папке бота (рядом с `fileserver_bot.py`)

---

### 2. `.client_log.json` (создаётся на клиенте)
**Назначение:** Логирование всех операций на локальном клиенте  

**Формат:**
```json
[
  {
    "timestamp": "2024-02-04T10:30:15",
    "operation": "upload",
    "filename": "document.pdf",
    "subfolder": "documents",
    "client_id": "home_pc"
  }
]
```

**Где создаётся:** В папке downloads на каждом клиенте
